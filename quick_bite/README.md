# Quick Bite

Quick Bite is a Java web-based food ordering application that supports both customer and admin functionality.

## Overview
The project is designed for ordering food online while allowing an admin to track and manage orders. It provides a simple system for customer interaction and order management.

## Features
- Customer-facing food ordering flow
- Admin dashboard for order tracking
- Java web application structure
- Frontend integration with JSP/Servlet-based web pages

## Tech Stack
- Java
- JSP / Servlets
- HTML/CSS/JavaScript
- Maven / Java web project structure

## Project Structure
```text
src/
  main/
    java/
    webapp/
```

## Run locally
1. Import the project into your Java IDE or server environment.
2. Configure the project as a Java web application.
3. Build and deploy it on a local server such as Tomcat.
4. Open the app in the browser.

## Notes
This is a practical food ordering project that demonstrates web application functionality for both users and administrators.
